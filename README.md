# Network Scanner

Сканер локальної мережі з веб-інтерфейсом (Flask) і набором мережевих інструментів.

## Структура

| Файл | Призначення |
|------|-------------|
| `app.py` | Веб-сервер і маршрути |
| `scanner.py` | Сканування (ping, ARP, hostname, порти, виробник) та історія пристроїв |
| `tools.py` | Усі додаткові інструменти. Новий інструмент = функція + запис у `TOOLS` |
| `templates.py` | HTML-сторінки |
| `requirements.txt` | Залежності (лише Flask) |
| `README.md` | Цей файл |

Усі файли мають лежати в одній папці. При роботі створюється `history.json`.

## Запуск

```
pip install -r requirements.txt
python app.py
```

Відкрий http://127.0.0.1:5000

## Сторінки

- **Пристрої** — список знайдених пристроїв, мітка «НОВИЙ» для тих, що з'явились уперше.
- **Сторінка пристрою** — деталі, своя назва, кнопки інструментів, посилання на веб-інтерфейс.
- **Інструменти** — окремі утиліти (див. нижче).
- **Історія** — усі пристрої, коли-небудь побачені, онлайн/офлайн.
- **Експорт** — `/export.csv` (відкривається в Excel) та `/export.json`.

## Інструменти

| Інструмент | Що робить |
|------------|-----------|
| Ping | Мін/середня/макс затримка, % втрат |
| Traceroute | Маршрут до вузла |
| Діагностика мережі | Роутер + інтернет + DNS одним кліком |
| DNS-пошук | IPv4/IPv6 і зворотний DNS |
| Whois | Власник домену або IP |
| Сканер портів | Власний діапазон портів (до 5000) |
| Банери сервісів | Що відповідають SSH/FTP/HTTP тощо |
| HTTP-інфо | Заголовок, сервер, авторизація веб-інтерфейсу |
| NetBIOS | Ім'я комп'ютера Windows |
| UPnP / SSDP | Смарт-ТВ, медіасервери, принтери |
| Wake-on-LAN | Увімкнення ПК за MAC |
| Виробник за MAC | Виробник мережевої карти |
| ARP-таблиця | Сусіди, яких знає система |
| Калькулятор підмереж | Маска, broadcast, діапазон хостів |
| Мій комп'ютер | Локальний/публічний IP, шлюз |
| Тест швидкості | Завантаження через Cloudflare |

## Безпека

- Сервер слухає лише `127.0.0.1`, запити з інших сайтів блокуються.
- Сканер портів, банери, HTTP-інфо, NetBIOS працюють тільки з адресами локальної мережі.
- Скануй лише власну мережу або ту, на яку маєш дозвіл.

## Нотатки

- Деякі пристрої не відповідають на ping, тому можуть не з'явитись.
- Traceroute на Linux/macOS потребує встановленої команди `traceroute`.
- Виробник визначається через api.macvendors.com (~1 запит/сек).
